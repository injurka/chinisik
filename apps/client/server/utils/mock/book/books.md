### Итоговая подробная модель данных (JSON) для `Book`

Объект `Book` представляет собой краткую информацию о книге, предназначенную для отображения на карточке в общем каталоге (на витрине). Он содержит только те данные, которые необходимы для визуального представления и базовой фильтрации.

#### `Book` (Корневой объект)

- `id` (строка): Уникальный идентификатор-слаг книги, используемый для навигации на страницу с детальной информацией (например, `le-petit-prince`).
- `title` (строка): Название книги для отображения на карточке.
- `author` (строка): Автор книги.
- `coverUrl` (строка): URL-адрес изображения обложки.
- `genre` (строка): Жанр книги, используется для фильтрации в каталоге (например, "Философская сказка").
- `difficulty` (строка): Общий, текстовый уровень сложности для быстрой оценки и фильтрации пользователем (например, "Начинающий", "Средний").

---

### Пример JSON для одной книги в каталоге

```json
{

  "title": "小王子 (Маленький принц)",

  "difficulty": "Начинающий"
}
```
