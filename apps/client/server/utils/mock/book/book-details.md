### Итоговая подробная модель данных (JSON) для `BookDetails`

Объект `BookDetails` представляет собой полную метаинформацию об одной книге, доступной для изучения китайского языка.

#### 1. `BookDetails` (Корневой объект)

- `id` (строка): Уникальный идентификатор-слаг книги, используемый для URL-адресов (например, `le-petit-prince`).
- `title` (строка): Название книги для отображения в каталоге.
- `author` (строка): Автор книги.
- `originalTitle` (строка): Оригинальное название книги (может совпадать с `title`).
- `coverUrl` (строка): URL-адрес изображения обложки книги.
- `genre` (строка): Жанр книги (например, "Современная проза", "Философская сказка").
- `summary` (строка): Краткое описание (аннотация) книги.
- `difficultyGeneral` (строка): **(Изменено)** Общая, текстовая сложность для быстрой фильтрации и понимания пользователя (например, "Начинающий", "Средний", "Продвинутый").
- `difficultyFormal` (строка): **(Изменено)** Формальный уровень сложности по китайской системе (например, "HSK 2", "HSK 4").
- `lexicalProfile` (объект): Лексическая статистика по книге.

#### 2. `LexicalProfile` (Вложенный объект)

Содержит статистику по словарному составу книги.

- `uniqueWords` (число): Общее количество уникальных слов в тексте.
- `basicVocabularyPercentage` (число): Процент слов, относящихся к базовой лексике.
- `advancedVocabularyPercentage` (число): Процент слов, относящихся к продвинутой лексике.

### Пример JSON для одной книги ("Маленький принц")

```json
{
  "id": "le-petit-prince",
  "title": "小王子 (Маленький принц)",
  "author": "Антуан де Сент-Экзюпери",
  "originalTitle": "Le Petit Prince",
  "coverUrl": "/images/books/placeholder.png",
  "genre": "Философская сказка",
  "summary": "Аллегорическая повесть-сказка, наиболее известное произведение Антуана де Сент-Экзюпери. История о маленьком мальчике, который путешествует с планеты на планету, встречая разных взрослых и познавая мир.",
  "difficultyGeneral": "Начинающий",
  "difficultyFormal": "HSK 2",
  "lexicalProfile": {
    "uniqueWords": 1800,
    "basicVocabularyPercentage": 90,
    "advancedVocabularyPercentage": 10
  }
}
```
