# Chinisik (Чайнизик) 🐉

**Ваше персональное додзё для погружения в мир китайского языка!**

---

Этот проект — моя песочница для экспериментов с современными веб-технологиями (привет, Nuxt 3 и Vue!) и попытка сделать изучение китайского чуть менее пугающим и более увлекательным, сочетая проверенные методики с возможностями ИИ. Я хотел создать не просто очередной набор инструментов, а уютное и интерактивное пространство, где можно было бы шаг за шагом осваивать иероглифы, разбираться в грамматике, тренировать произношение и просто получать удовольствие от процесса.

## ✨ Ключевые особенности

"Чайнизик" стремится быть многофункциональным помощником на вашем пути изучения языка:

- **Интерактивные Радикалы (Ключи):** Исследуйте 214 иероглифических ключей, лежащих в основе письменности. Узнайте их значение, произношение и роль в построении иероглифов.
- **Словарь HSK:** Изучайте и повторяйте лексику для всех уровней HSK (1-9?). Фильтруйте, ищите, просматривайте слова с пиньинем, переводом и примерами.
- **Лаборатория HSK:** Тренируйте слова HSK с помощью интерактивных карточек (свайп влево/вправо для "знаю"/"повторить").
- **Таблица Пиньинь:** Наглядное пособие по системе транскрипции пиньинь, включая инициали, финали и их сочетания.
- **Тематический Словарь:** Пополняйте словарный запас по конкретным темам (вежливость, путешествия, еда, цвета и т.д.).
- **Глоссарий и Статьи:** Раздел для углубленного изучения грамматики, лексических нюансов и культурных аспектов языка.
- **Лингвистический Анализ (AI):** Экспериментальная функция на базе LLM для глубокого анализа введенного китайского текста (структура предложения, части речи, роли компонентов иероглифов).
- **Практика Написания Иероглифов:** Интерактивная доска для тренировки написания иероглифов с возможной (в будущем) проверкой через ИИ.
- **Персональные Заметки:** Возможность вести личные заметки по учебе с поддержкой Markdown.
- **PWA & Оффлайн Доступ:** Установите приложение на устройство и пользуйтесь некоторыми функциями даже без интернета (благодаря Service Worker). (`@vite-pwa/nuxt`, `service-worker`)
- **Push-уведомления:** (Опционально) Получайте напоминания или уведомления.
- **Аутентификация:** Регистрация и вход для сохранения прогресса и доступа к персональным разделам.

## 🛠️ Технологический стек

- **Фреймворк:** [Nuxt 3](https://nuxt.com/) (Vue 3)
- **UI Библиотека:** [Vuetify 3](https://vuetifyjs.com/)
- **Управление состоянием:** [Pinia](https://pinia.vuejs.org/)
- **Стилизация:** SCSS (с модульной системой тем)
- **Язык:** TypeScript
- **API:** Nuxt Server Routes (с использованием моков для разработки), кастомный модуль API для типизированных запросов.
- **Линтинг/Форматирование:** ESLint (@antfu/eslint-config)
- **PWA:** @vite-pwa/nuxt
- **AI:** Потенциальное использование LLM для лингвистического анализа и проверки написания (через `llm` эндпоинты).

## 🏗️ Структура Проекта (Краткий обзор)

Проект старается следовать принципам Vertical Sliced, группируя код по функциональным модулям и общим компонентам:

- `assets/`: Глобальные стили (SCSS), шрифты, изображения.
- `components/`: UI компоненты Vue.
  - `domain/`: Переиспользуемые компоненты, связанные с предметной областью (например, `HieroglyphWord`, `PinyinText`).
  - `modules/`: Компоненты, реализующие конкретные фичи/разделы сайта (HSK, Ключи, Пиньинь и т.д.).
  - `shared/`: Общие, не зависящие от предметной области UI компоненты (Header, Footer, Dialogs).
- `layouts/`: Макеты страниц Nuxt.
- `middleware/`: Маршрутные Middleware Nuxt (например, для проверки аутентификации).
- `modules/`: Кастомные модули Nuxt (например, модуль `1.api` для работы с API).
- `pages/`: Файлы маршрутизации страниц Nuxt.
- `plugins/`: Плагины Nuxt (например, для инициализации API).
- `server/`: Бэкенд часть Nuxt.
  - `api/`: Обработчики API маршрутов.
  - `utils/`: Вспомогательные функции и мок-данные для серверной части.
- `service-worker/`: Логика Service Worker (PWA, Push-уведомления).
- `shared/`: Общий код, используемый и на клиенте, и на сервере (типы, константы, API хендлеры, composables).
- `store/`: Глобальные хранилища Pinia (например, `auth.store.ts`).
